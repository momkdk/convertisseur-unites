# convertisseur-unites

🔗 **Essayer en ligne, gratuitement : [momkdk.github.io/convertisseur-unites](https://momkdk.github.io/convertisseur-unites/)**

Conversion d'unités : longueur, poids, volume, température, vitesse. Python pur, aucune
dépendance, licence MIT.

## Utilisation

```
python -m convertisseur_unites longueur 10 km mile
python -m convertisseur_unites temperature 100 c f
python -m convertisseur_unites vitesse 36 km/h m/s
```

Catégories disponibles : `longueur`, `poids`, `volume`, `vitesse`, `temperature`.

## Tests

```
python -m unittest discover -s tests -v
```
